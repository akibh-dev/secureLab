# Contributing to SecureLab

Follow the phase workflow and local checks before opening a Forgejo PR. [Agent workflow](agents.md) · [Setup and test commands](README.md#check-a-change)

A lesson starts with a measurable learning objective and fictional application. Define the expected behavior before choosing policy options. Include a legitimate success, restricted outcomes, relevant boundary cases, three increasing hints, a reasoning question and an explanation. Use stable lesson and case IDs, increment the lesson version for assessment changes, and cite the applicable primary reference. Run the catalog validator to check the reference policy and every distractor. The [pilot lesson](packages/lab-content/src/pilot.ts) is an example.

For curriculum review, inspect trusted context, scopes, public responses, state changes, hints and references. Reproduce a failure and a completion on the built site and check the workspace with a keyboard.
